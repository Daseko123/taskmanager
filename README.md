# Task Manager

## Sovelluksen tarkoitus

Task Manager on C# Windows Forms -sovellus tehtävien hallintaan.

Sovelluksella käyttäjä voi lisätä, poistaa ja suorittaa tehtäviä.

## Sovelluksen toiminta

Käyttäjä kirjoittaa tehtävän tekstikenttään ja painaa Add-painiketta.

Complete-painikkeella tehtävä merkitään tehdyksi.

Remove-painikkeella valittu tehtävä poistetaan.

Settings-painikkeella avataan toinen näkymä.

Settings-näkymässä kaikki tehtävät voi poistaa.

## Käytetyt rakenteet

Ohjelmassa käytetään if-else-rakenteita, switch-rakennetta, for-silmukkaa ja try-catch-rakennetta.

Ohjelma on jaettu useisiin funktioihin.

## Kaksi näkymää

Form1 toimii pääikkunana.

SettingsForm toimii toisena näkymänä.

## Jatkokehitys

- Tehtävien prioriteetit
- Määräpäivät
- Tehtävien muokkaaminen
- Hakutoiminto
- Tehtävien järjestäminen
- Erilaiset väriteemat
